# Overview

This document collects, for each GUI framework demonstrated in this repo, a
brief comparison: pros, cons, and guidance on when to choose it and when not
to. Each project's own `README.md` covers environment setup, build/run/debug,
and packaging; each project's own `IMPLEMENTATION.md` tracks its completeness
checklist and side notes. This file is the cross-project summary, updated as
each contester's demonstrator is implemented.

See [README.md](README.md) for the demonstrator app (a tabbed clock app with
wallclock, stopwatch, and synctime tabs) and the list of contesters.
